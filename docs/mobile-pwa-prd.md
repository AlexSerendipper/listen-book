# Listen Book Mobile PWA 产品需求文档

> 文档版本：v0.4
>
> 文档状态：已批准，M0 开发与自动验证完成，iPhone 实机验收未完成
>
> 最终归档仓库：`D:\CodexProject\listen-book`
>
> 产品形态：iPhone 主屏幕 Web App（PWA）
> 配套产品：Windows `listen-book`

## 1. 产品定位

Listen Book Mobile PWA 是 Windows `listen-book` 的移动端离线阅读伴侣。

Windows 端是主书库，保存原始书籍、解析结果和长期备份；iPhone 保存可删除、可重新下载的离线副本。用户可在电脑在线时通过 Tailscale 私有网络下载书籍和同步文字阅读进度；电脑离线或手机没有网络时，仍可阅读已下载内容并保存手机本地进度。“主书库”不表示电脑进度永远优先，用户仍可明确选择用手机文字进度覆盖电脑。

移动端不通过 App Store、TestFlight 或 IPA 分发，也不依赖公共云服务器。

当前可用能力以 §12.1 的“M0 当前实现状态”为准。除 §12.1 明确列出的能力外，§7–§11 描述的是完整 MVP 产品目标，不代表已经交付。

## 2. 已确认的产品决策

- Windows 端和 Mobile PWA 放在同一个 `listen-book` Git 仓库中，但保持独立前端模块。
- 第一阶段先完成 M0 技术验证，通过 iPhone 实机验收后再开发完整 MVP。
- MVP 只支持当前用户的一部 iPhone；多移动设备延后。
- Windows 后端继续仅监听 `127.0.0.1:8765`，由 Tailscale Serve 提供 Tailnet 内的可信 HTTPS。
- Windows 与 iPhone 必须安装 Tailscale、加入同一 Tailnet 并保持连接；Tailscale 断开时，已配对手机仍可离线阅读，但不能访问电脑或同步。
- 允许离家同步：只要 Windows 电脑开机、联网且 `listen-book` 与 Tailscale 正常运行，iPhone 即可同步。
- Tailscale 只提供私有网络通道；产品仍使用不含秘密的安装二维码、一次性短码和可撤销设备凭证进行应用级配对。
- 电脑端发起同步时，iPhone PWA 必须已打开并处于前台；否则直接提示“请先在手机上打开应用”，不创建等待任务。
- `电脑 → 手机`全量同步不会删除手机独有或电脑端已不存在的手机离线副本。
- 电脑中的书籍文件内容发生变化并产生新 SHA-256 时，视为一本新书，不迁移旧进度。
- 手机第一版只提供文字阅读，不提供朗读、音频下载、音频播放或播放进度同步。
- 跨设备只同步文字阅读位置；电脑端语音位置、声音、倍速和音量保持不变。
- 每本书每个目标端仅保留最近一条被覆盖进度，用于一次立即撤销，不保留长期历史。
- 移动端采用针对小屏和单手操作重新设计的界面，不要求复刻桌面端视觉。
- 手机书库默认只展示精简书名；点击书名后以单开手风琴展示作者、格式、离线状态和`下载 / 继续阅读`操作。
- 手机展示标题保留主书名与版本信息，去掉 EPUB 标题元数据中的宣传简介；桌面数据库继续保留原始完整标题。
- 手机书库只按 iPhone 端实际翻页产生的最近阅读时间倒序排列；从未阅读的书排在其后并按书名排序。
- 阅读器以手势和正文点击翻页：左滑或点击右半屏进入下一页，右滑或点击左半屏返回上一页；长按选字、拖动选区、链接和图片不触发翻页。
- M0 使用现有书库中一本含封面或正文图片的 EPUB 作为真实样本。

“手机独有书籍”主要指电脑后来删除的书籍副本，或电脑文件变化后留在手机上的旧内容哈希版本；MVP 不支持从手机导入新书。

## 3. 产品目标

### 3.1 核心目标

- 用户能从 Safari 将产品添加到 iPhone 主屏幕，并像普通 App 一样启动。
- 用户能安全配对一部 iPhone，随时从电脑端撤销该设备。
- 用户能把电脑书库中的 TXT、Markdown 和 EPUB 下载到手机。
- 用户在飞行模式下仍能打开书库、阅读正文和图片、翻页并恢复进度。
- 用户能在电脑端一键同步全部书籍，并明确选择文字进度覆盖方向。
- 用户能对单本书执行`电脑进度覆盖手机`或`手机进度覆盖电脑`。
- 不同屏幕、字号和分页结果下，两端恢复到相同文字内容，而不是相同视觉页码。
- 手机副本被删除或 PWA 数据丢失时，不影响电脑主书库。

### 3.2 成功标准

- 首次配对完成后的默认书库页面，从选书到开始下载不超过 3 次点击；滚动、等待和系统授权不计为点击。
- 书籍显示“已离线”后，飞行模式下可以完整打开正文与已下载图片。
- PWA 冷启动后 3 秒内显示本地书库或明确的本地存储错误。
- 电脑端一次选择方向、一次确认即可启动全量同步。
- 正常锚点同步后，两端定位到同一段落且字符偏差不超过 32 个 Unicode code point；发生降级恢复时必须明确提示，且不计作精确恢复通过。
- 下载或同步中单本失败不影响其他书籍，并可单独重试。
- 同步写入失败时，目标端旧进度保持不变。
- MVP 通过人工验收，不引入遥测、广告或行为分析。

## 4. 非目标

- 多人账号、家庭共享、社交功能。
- 公共云存储和匿名公网同步入口。
- 电脑关机时跨设备同步。
- 手机向电脑导入新书。
- 移动端音频生成、下载、播放和播放进度同步。
- 同步桌面悬浮窗、窗口状态、分页缓存、语音或播放设置。
- DRM 电子书导入或破解。
- 多部手机同时配对。
- 书签、笔记、全文搜索、推送通知和横屏专用布局。

## 5. 产品原则

### 5.1 离线优先

本地书库、打开已下载书籍、翻页和保存进度不得依赖网络。界面必须区分“电脑书库中存在”和“手机已离线”。

### 5.2 电脑是主书库

手机删除书籍仅删除手机副本。全量同步只新增或更新电脑书籍，不自动删除手机独有副本。

### 5.3 同步内容位置，不同步视觉页码

跨设备进度使用以下内容锚点：

```text
book_content_hash
parser_version
chapter_index
paragraph_index
character_offset
anchor_text_hash
anchor_version
```

视觉页码只用于当前设备显示和快速恢复，不作为跨设备同步依据。

### 5.4 用户明确选择覆盖方向

系统不比较更新时间、页码大小或阅读百分比，不自动判断哪一端更新，也不合并进度。用户必须选择：

```text
电脑 → 手机
手机 → 电脑
```

只有 `(book_content_hash, parser_version, anchor_version)` 兼容时才允许覆盖。解析包不兼容时，手机旧包仍可离线阅读，但必须先更新解析包才能同步进度。

来源端没有有效文字进度时，结果为`跳过：来源无进度`，不得清空目标端；来源锚点非法时同步失败，目标端和历史均不改变。目标端旧进度在覆盖成功前不得改变。覆盖成功后保留最近一条历史用于撤销。

### 5.5 可恢复、可解释

所有手机书籍都可从电脑重新下载。尚未同步的手机进度可导出 JSON。同步、下载、存储不足和认证失败都必须展示明确状态与可执行的下一步。

## 6. 总体使用模型

### 6.1 在线状态

```text
Windows listen-book (127.0.0.1:8765)
        │
        │ Tailscale Serve / 私有 HTTPS
        ▼
iPhone Mobile PWA（前台）
```

在线时可以配对、浏览电脑书库、下载书籍、执行单本或全量进度覆盖。同步数据不经过公共 Funnel 或第三方书籍服务。

### 6.2 离线状态

```text
iPhone Mobile PWA
├─ 缓存的应用外壳
├─ 本地书籍与图片
├─ 本地解析结果
└─ 本地阅读进度
```

离线时仅展示本机内容，不自动尝试覆盖电脑进度。

## 7. 核心用户流程

### 7.1 首次安装与配对

1. 用户启动 Windows `listen-book`，进入“连接手机”。
2. 电脑确认 Tailscale Serve 可用，并显示不含配对秘密的安装二维码，以及一枚 5 分钟有效的一次性配对短码。
3. 用户使用 iPhone Safari 扫码打开安装引导，将页面添加到主屏幕。
4. 用户从主屏幕独立打开 PWA，在 PWA 内输入短码并提交配对请求；不假设 Safari 与主屏 PWA 共享 IndexedDB、Cache Storage 或凭证。
5. 电脑端显示设备摘要并要求确认。
6. 确认后，主屏 PWA 安全领取可撤销设备凭证；永久凭证不出现在 URL、二维码、日志或导出文件中。
7. PWA 缓存应用外壳并尝试申请持久存储，电脑显示已配对设备和最近在线时间。

### 7.2 单本下载

1. 用户在手机打开“电脑书库”。
2. 选择一本未下载书籍，查看格式、大小和预计存储占用。
3. PWA 下载元数据、解析内容、图片资源和原始书籍副本。
4. 系统支持中断恢复，并逐项校验 SHA-256。
5. 所有必需资源校验成功后，状态才变为“已离线”。

校验失败时删除损坏资源并提示重试；不完整下载不得显示为可离线。

### 7.3 电脑端全量同步

1. 用户先在 iPhone 打开 PWA，并保持前台。
2. 用户在电脑端点击“一键同步全部”。
3. 如果手机不在线或不在前台，电脑提示“请先在手机上打开应用”，且不创建任务。
4. 用户选择`电脑 → 手机`或`手机 → 电脑`。
5. 电脑展示影响书籍数量、两端位置摘要和覆盖说明。
6. 用户确认后执行；单本失败不终止批次。
7. 完成页展示成功、部分完成、跳过、失败和可重试列表。

`电脑 → 手机`：下载电脑主书库全部书籍；只有内容哈希、解析版本、锚点版本兼容且必需资源完整时才跳过内容下载，并以电脑文字进度覆盖兼容书籍的手机进度；不删除手机其他书籍。

`手机 → 电脑`：不上传手机独有书籍，只对两端共有书籍以手机文字进度覆盖电脑文字进度；电脑播放进度与语音设置不变。

### 7.4 单本进度同步

每本共有书籍提供：

- `电脑进度覆盖手机`
- `手机进度覆盖电脑`

执行前显示两端章节、附近文字和更新时间。用户确认后原子覆盖，成功后允许撤销最近一次覆盖。

M0 当前入口位于手机阅读器右上角 `Aa` 菜单。手机保持前台并连接电脑时，可点击`电脑进度 → 手机`或`手机进度 → 电脑`执行单本文字进度覆盖；M0 不包含电脑端主动推送按钮、覆盖预览和撤销界面，这些仍属于完整 MVP。

### 7.5 离线阅读

- 翻页 1 秒后保存本地文字进度。
- 切换章节、切换书籍、页面进入后台时立即保存。
- 正文区域保持固定，不使用页面级纵向滚动承载主要翻页。
- 左滑或点击正文右半屏进入下一页；右滑或点击正文左半屏返回上一页。
- 只有普通短按触发点击翻页；长按选择文字、拖动选区、点击链接或图片时不得翻页。
- 字号、行距、主题或屏幕方向改变后重新分页，并按内容锚点恢复。

## 8. 功能需求

### 8.1 PWA 与书库

- 提供 Manifest、图标、主题色、独立显示模式和离线启动 Service Worker。
- 书库分为“已下载”“电脑书库”“下载中”。
- 书库默认只展示“主书名＋版本”；EPUB 原始完整标题仍保留在电脑端，不把宣传简介当作手机列表标题。当前规则取第一个括号或书名冒号前的主标题，并保留第一个包含“版、修订、增订、珍藏、典藏”等版本标记的括号内容。
- 点击书名后展开作者、格式、离线状态和`下载 / 继续阅读`按钮；同一时间只展开一本，点击已展开书名可收起，返回列表或重开 PWA 时默认全部收起。
- EPUB 作者读取 `DC creator`；缺失时显示“未知作者”。TXT、Markdown 在完整 MVP 定义作者来源前同样显示“未知作者”。
- 下载完成后留在书籍列表，当前书保持展开，按钮变为`继续阅读`，不自动进入阅读器。
- 至少成功翻过一页后才更新 iPhone 最近阅读时间；已阅读书按该时间倒序，未读书随后按书名排序，不使用电脑端最近阅读时间参与排序。
- 完整 MVP 可在展开详情中继续增加封面、阅读摘要、本地占用和同步状态，但不得破坏默认收起的信息层级。
- 每本书同时维护三个正交状态，不用单一枚举互相覆盖：
  - `offline_status = not_downloaded | downloading | offline | incomplete | storage_error`
  - `progress_status = clean | locally_modified | remote_changed | unknown`
  - `sync_status = idle | syncing | succeeded | partial | failed`
- `locally_modified`仅表示本机文字进度自最近一次成功覆盖后发生变化；下载成功不会清除该状态，只有对应方向的进度覆盖成功才清除。
- 显示当前是否连接电脑、上次成功同步时间和最近一次方向。

### 8.2 阅读器

- 完整 MVP 支持 TXT、Markdown、EPUB；当前 M0 只保证并验收 EPUB 离线阅读。
- 支持左右滑动和正文左右半屏短按翻页，并在章节边界自然进入上一章或下一章。
- 不显示底部上一页/下一页按钮；章节与本地页码显示在顶部副标题。
- 支持长按选择文字；长按、拖动、链接和图片交互优先于点击翻页。
- 支持字号、行距、浅色、深色和跟随系统主题。
- EPUB 封面、图片页和扉页完整显示，避免把单张图片拆分到两页。
- EPUB 固定宽度、禁止换行或桌面分栏样式必须在手机列宽下重新流式排版，不得裁切右侧正文；分页栏宽必须与翻页步长一致。
- 视觉页码是本地表现，不参与跨设备同步。
- 移动端不展示任何朗读或音频控制。

### 8.3 离线内容管理

- 展示 PWA 已用空间和浏览器估算配额。
- 首次安装后尝试请求持久存储，但不承诺 iOS 永不清理数据。
- 下载前检查预计空间；明显不足时阻止下载。
- 支持暂停、继续、取消、删除单本副本和清空全部离线内容；默认只删除正文、图片、原始文件和下载临时块，保留文字进度、配对凭证、设置和同步记录。
- 存在未同步进度时提供“先同步”“导出后删除”“取消”，不使用只有确认/取消的笼统提示。
- 清除凭证和进度属于独立的“重置移动应用数据”操作，并要求再次确认。

### 8.4 手动备份

- 导出包含书籍内容哈希和文字进度的 JSON。
- 可从 JSON 恢复本机文字进度。
- 导出文件不包含书籍全文、图片、永久凭证或播放设置。
- 找不到匹配内容哈希时跳过并明确提示。
- 导入前校验 schema、字段类型、文件大小和锚点边界，并展示匹配、跳过和冲突数量。
- 合法匹配项经用户确认后覆盖，覆盖前写入最近历史；单条非法记录只跳过该条，文件结构整体非法时不写入任何数据。
- 导入不得恢复凭证、同步时间或设备身份。

## 10. 安全与隐私

- FastAPI 继续只监听本机回环地址。
- 仅使用 Tailscale Serve 提供 Tailnet 内 HTTPS，不启用 Funnel。
- 所有移动 API 均验证应用级设备凭证；不能只依赖 Tailscale 网络成员身份。
- 首次配对使用短时、一次性、确认后失效的随机令牌。
- 永久设备凭证可撤销，不写入 URL、日志或导出文件。
- 配对、撤销和同步结果写入本地安全日志，但不记录书籍正文、附近文字或凭证。
- 设备撤销后，既有离线书籍和本地进度继续可读且不自动清除；联网 API 返回`设备已撤销，请重新配对`。重新配对不得静默删除旧书或未同步进度。
- 不加载第三方脚本、统计 SDK、广告或遥测。
- 书籍正文只在用户的 Windows、iPhone 和两者之间的加密通道中存在。

## 11. 非功能需求

- 最低支持 iOS 17，实际优先验证用户当前 iPhone 与当前正式 iOS。
- 本地书库首屏 3 秒内可用；缓存命中时普通翻页无明显等待。
- 进度保存不得阻塞翻页。
- 下载支持中断恢复；损坏或不完整文件不进入离线完成状态。
- 数据结构升级必须向前迁移，不静默清空桌面或手机数据。
- PWA 应用外壳更新不得删除书籍和进度数据库。
- 状态不能只依赖颜色；主要按钮具有文本或 `aria-label`；触控目标适合单手操作。

## 12. 分阶段范围与验收

除非明确标注为 M0，§7–§11 的完整功能要求均属于完整 MVP。M0 只需满足 §12.1 明列能力，可以在下载失败后从头重试，不要求暂停、取消或跨启动续传；但所有阶段都必须满足认证、校验失败不标记离线、不同步播放字段和不破坏现有数据等安全底线。

## 13. 异常处理原则

- 手机不在前台：不创建电脑发起的同步任务。
- 手机执行中离开前台或失联：任务进入终态且不自动恢复；已完整提交的书籍保留，进行中的进度事务回滚，未完整下载保留为中断状态，未开始项标记失败。返回前台后只能创建新任务或显式重试。
- 下载断网：保留可续传状态；恢复网络后由用户继续。
- 校验失败：删除损坏资源，不标记离线完成。
- 同步失败：目标端原进度不变。
- 来源端没有有效文字进度：跳过该书，不重置目标端。
- 内容哈希相同但解析器或锚点版本不兼容：保留旧包离线可读，更新解析包前禁止进度覆盖。
- 全量同步单本失败：继续处理其他书籍，并在完成页列出失败项。
- 未选择方向或未确认：不得写入任何跨设备进度。
- 书籍文件哈希改变：显示为新书，旧手机副本和旧进度保持不变。
- 单本内容下载成功但进度覆盖失败：书籍保留并显示“部分完成：书籍已下载，进度未覆盖”。

## 14. 开发与发布约束

- 不影响现有桌面阅读、听书、悬浮窗、TTS、导入和书库功能。
- Mobile PWA 使用独立路由、静态资源、状态和样式作用域。
- 兼容性数据库变更只能新增字段或表，并提供迁移与回归测试。
- 未经用户评审通过技术方案，不进入产品代码实现。
- `listen-book-ios` 在文档迁移和产品验收完成前保留，不执行删除。
