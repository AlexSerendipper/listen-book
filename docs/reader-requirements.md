# 阅读器产品约束

本文档记录听书阅读器的长期产品约束。后续涉及阅读器 UI、EPUB 解析、分页、图片展示、播放控制或键盘交互的改动，都应先阅读并遵守本文档。

Git commit 记录只能说明历史上做过什么，不应作为需求来源。本文档是后续开发和 AI 协作时的主要产品 memory。

## 核心原则

- 阅读区域尺寸必须固定，不能被 EPUB 内容、图片、标题、引文框或原书样式撑高。
- 内容区域不允许出现滚动条；用户阅读下一部分内容应通过翻页完成，而不是在当前页内滚动。
- 主页面不应因为阅读内容出现浏览器级滚动条；左侧书库、目录弹窗等辅助区域可以在自身内部滚动。
- 新增功能不能回归固定阅读区域、无滚动阅读、键盘翻页和播放控制等基础体验。

## EPUB 页面展示

- 扉页、封面、图片页必须作为单页展示。
- 图片不能被拆分到多页；图片过大时应缩放适配当前页。
- EPUB 原样式可以保留视觉特征，例如标题颜色、边框、圆角框、居中排版等，但不能破坏固定阅读区域。
- EPUB 中过大的 margin、padding、百分比留白或标题间距，应通过样式覆盖压缩到适合当前阅读器视口。
- 如果单页内容放不下，应通过分页承载；不要通过拉高阅读区域或开启内容滚动解决。

## 结构化内容

- 圆角引文框、边框块、居中块等结构容器应整体保留。
- 同一个结构容器内的多个段落不能被拆成多个视觉框。
- 例如一个圆角引文框内包含作者名和引文两个 `<p>` 时，网页中也应显示为一个圆角框。
- 普通正文段落仍可按段落参与分页，避免整章被合并成过大的单页块。

## 阅读器布局

- 书库默认为关闭的悬浮抽屉，脱离正文布局并覆盖在阅读区上方。
- 书库入口使用书名左侧的书本图标，不以独立悬浮文字遮挡页面。
- 打开或关闭书库不能改变正文宽高、触发分页重算、移动当前视觉页或干扰音频播放；点击抽屉外区域或按 `Esc` 应关闭书库。
- 整个阅读播放器面板应在连续翻页时保持固定尺寸。
- 页码区、正文区、进度条和底部控制按钮的位置应稳定，不随当前页内容多少上下跳动。
- 正文区应占用固定剩余空间，内容不能把底部进度条或按钮挤出可视区域。
- 页面内容超出当前页高度时，应优先由分页逻辑处理；前端布局层必须防止内容撑开外层容器。

## 键盘与播放控制

- 左箭头切换到上一页。
- 右箭头切换到下一页。
- 空格键控制播放/暂停。
- 键盘快捷键不应破坏输入框、搜索框等文本输入场景。
- 切换页面、章节、语音、语速等播放相关状态时，应避免不必要的音频重新生成或重新加载；如必须重新加载，应有明确原因。

## 播放跟随与当前页

- 播放状态和视觉页状态是相关但不同的状态：音频可以进入下一段，阅读区不应仅因为音频段结束就强制跳到下一段起始页。
- 播放中页面应跟随当前高亮句子，而不是跟随后端段落起点。
- 如果当前高亮句子已经在当前视觉页内可见，不应自动翻页。
- 如果当前高亮句子不在当前视觉页内，可以自动翻到该句所在视觉页；自动翻页应按视觉页逐页推进，不能一次跳过多页。
- 同一朗读段自然进入后续句子时，自动跟随不得回到更早的视觉页；用户主动点击前文或拖动进度条回退除外。
- 跨页段落、短标题、非朗读块、图片块和重复引文都不能导致播放跟随逻辑误跳页。
- 阅读区尺寸变化触发异步分页重算时，应保留当前播放句和视觉页锚点；重算期间发生的新点击必须优先于旧页面状态。
- “回到当前页”按钮的目标是最后播放句所在视觉页；只要当前浏览页不包含该句就应启用，包括浏览页和播放页位于同一段落的情况。
- 点击“回到当前页”时，应定位到当前高亮句子所在视觉页；不能简单回到当前朗读段落的起始视觉页。
- 返回播放页导致章节 DOM 重建时，必须恢复播放句的定时映射和高亮状态。
- 暂停或停止后仍保留最后播放位置。重新打开书籍时先恢复最后阅读内容，“回到当前页”仍指向最后播放句。
- 最后阅读位置必须保存章节、段落、句子及页内偏移等内容锚点，不能把依赖窗口尺寸的固定视觉页码直接作为持久化依据。
- 点击句子开始播放时，应定位到被点击句子的播放位置，但不应破坏当前章节的视觉分页结果。

## 验收标准

- 连续翻页时，阅读面板高度、正文区域高度、进度条位置和底部按钮位置保持不变。
- 主页面右侧不出现由阅读内容导致的浏览器滚动条。
- 当前页内容区域内部不出现滚动条。
- 扉页按单页展示，没有被拆成多页，也没有异常大面积空白。
- 封面和图片页按单页展示，图片完整可见并按比例缩放。
- EPUB 样式页不会因为标题、居中块、引文框或大间距把阅读区域撑高。
- 圆角引文框中的作者名和引文保留在同一个框内。
- 左右箭头翻页、空格播放/暂停可用。
- 标黄句子在当前视觉页可见时，“回到当前页”按钮应禁用。
- 翻到同段落内不包含标黄句子的其他视觉页时，“回到当前页”按钮应立即启用。
- 点击“回到当前页”后，应回到标黄句子所在视觉页。
- 关闭并重新打开书籍时先显示最后阅读内容；若已有播放历史，可通过“回到当前页”返回最后播放句。
- 反复打开和关闭书库时，阅读区尺寸、分页结果、当前页、音频状态和高亮句保持不变。
- 一段音频播放结束后，如果下一句或下一段仍在当前视觉页可见，不应自动翻页。
- 播放跨页长段落时，应随标黄句子逐页推进，不能回跳，也不能一次跳过多页。

## 回归检查建议

每次修改阅读器相关功能后，至少手工检查以下场景：

- 普通正文页。
- EPUB 样式标题页。
- 圆角引文框页。
- 封面、扉页或图片页。
- 连续翻页两到三页后的阅读面板稳定性。
- 播放中翻页、暂停、继续播放。
- 音频段刚好在当前页中间结束时，页面不应因为段落切换而误翻页。
- 调整窗口尺寸触发分页重算后，不等待重算完成，真实点击目标句的上一句并以 1 倍速从句首自然播放到目标句；高亮句应正常前进且不重置到本段第一句，视觉页索引、实际列索引和横向滚动位置均不应向前回退。
- 播放并暂停一句后翻到同段其他视觉页，检查“回到当前页”可用并准确返回；再翻到别处、重开书籍，检查最后阅读锚点和播放页分别正确恢复。
- 连续打开和关闭书库，确认没有分页重算，正文位置和音频播放互不影响。
- 同一句或相似引文在页面上重复出现时，标黄句子和“回到当前页”仍应定位准确。

推荐快速检查命令：

```powershell
node --check app/frontend/app.js
.\.venv\Scripts\python.exe -m unittest discover -s tests
```
